FitSense for Windows 10 and Windows 11 (x64)

Extract the entire archive to a writable local directory and run FitSense.exe.
Keep FitSense.portable and runtime beside FitSense.exe. FitSense creates data
in the same directory. Keep data when updating the application.

Microsoft Edge WebView2 Evergreen must already be installed. If it is missing,
use Microsoft's offline x64 WebView2 installer or the FitSense setup executable.
The portable archive includes the Python runtime that FitSense uses.
Python and frontend dependency notices are under runtime.

Open Wardrobe to set up encrypted storage or restore a FitSense backup.
Keep your recovery passphrase and a backup outside this directory. Close
FitSense before copying portable data. Restore into an unused vault.
